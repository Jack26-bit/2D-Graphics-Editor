# MASTER PROMPT

Act as a senior C programmer, Data Structures instructor, and Computer Graphics laboratory mentor.

Generate a COMPLETE, COMPILABLE, and WELL-DOCUMENTED C program for a menu-driven 2D Graphics Editor using a character-based canvas.

## PROJECT GOAL

Design and implement a console-based 2D Graphics Editor that allows users to draw, modify, delete, and manage graphical objects on a 2D character canvas.

The program must be suitable for a Data Structures and Graphics Programming laboratory assignment.

---

# TECHNICAL REQUIREMENTS

## 1. Canvas System

Use a global 2D character array as the drawing canvas.

Example:

```c
#define WIDTH 50
#define HEIGHT 20

char canvas[HEIGHT][WIDTH];
```

Requirements:

* Canvas size should be configurable using macros.
* Initialize every cell with '_' (underscore).
* Draw graphical objects using '*' (asterisk).
* Prevent drawing outside canvas boundaries.
* Support complete canvas redraw.

---

## 2. Shape Support

Implement the following shape drawing functions:

```c
void drawLine(...);
void drawRectangle(...);
void drawTriangle(...);
void drawCircle(...);
```

Each function must be implemented separately.

---

## 3. Drawing Algorithms

### Line

Use Bresenham’s Line Drawing Algorithm.

Requirements:

* Support all slopes.
* Integer arithmetic only.

### Circle

Use Midpoint Circle Algorithm.

Requirements:

* Use circle symmetry.
* Plot all 8 octants.

### Rectangle

Draw rectangle using four line segments.

### Triangle

Draw triangle using three line segments.

---

## 4. Shape Type Enumeration

Use an enum:

```c
typedef enum
{
    LINE,
    RECTANGLE,
    TRIANGLE,
    CIRCLE
} ShapeType;
```

---

## 5. Object Structure

Create a graphical object structure:

```c
typedef struct
{
    int id;
    ShapeType type;

    int x1;
    int y1;

    int x2;
    int y2;

    int x3;
    int y3;

    int radius;

    int visible;
} GraphicObject;
```

Requirements:

* Store all necessary shape information.
* Every object must have a unique ID.
* Maintain visibility status.

---

## 6. Object Storage

Create an object database:

```c
#define MAX_OBJECTS 100

GraphicObject objects[MAX_OBJECTS];
```

Requirements:

* Store at least 100 objects.
* Track object count.
* Generate unique object IDs automatically.
